Pārsi Read: file guide

index.html       Home (front page)
alphabet.html    Alphabet
read.html        Read
scramble.html    Scramble
colloquial.html  Let's go colloquial
about.html       About

css/style.css    All styling, shared by every page
js/data.js       The sentence list and illustrations (edit this to add content)
js/alphabet.js, read.js, scramble.js, colloquial.js   One script per page

To add a sentence: copy an entry in js/data.js and edit it.
To change the look: edit css/style.css.
Header, nav and footer are repeated in each HTML file (plain HTML has no includes), so change them in all six.
Open index.html in a browser to run the site, or upload the whole folder to any static host.
